# nvim-config
**Requirements**: [vim-plug](https://github.com/junegunn/vim-plug)

Trying my best to migrate from Zed and VSCode with ease

### Key Notation
- M: Alt key
- C: Ctrl key
- S: Shift key
- leader: Space key (Space + e = leader + e)

### Navigation & Completion
- <M - j>: Next item
- <M - k>: Previous item
- <M - Down>: Move the current line down
- <M - Up>: Move the current line up
- <M - S - Down>: Add a new cursor below
- <M - S - Up>: Add a new cursor above

### File & Tabs
- <C - e>: Open file finder
- <C - Shift - e>: Open recent files
- <M - b>: Toggle focus between NvimTree and workspace
- <M - S - b>: Toggle NvimTree
- <M - l>: Next buffer/tab
- <M - h>: Previous buffer/tab
- <M - w>: Close current buffer/tab
- <M - q>: Quit all

### LSP - Go to & Docs
- gd: Go to definition
- gD: Go to declaration
- gr: Go to references
- K: Show hover docs
- <C - k>: Show function params

### Diagnostics
- <Space - e>: Show error under cursor
- <Space - q>: Open all errors
- [d: Previous diagnostic
- ]d: Next diagnostic
- <C - `>: Toggle focus error window
- <C - S - `>: Hide error window
